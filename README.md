# 온기

고인과 반려동물을 기억하는 한국어 추모 서비스의 첫 버전입니다.

## 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
cd /workspace/ai
npm start
```

기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. 개발 중 자동 재시작은 `npm run dev`, 서버 검증은 `npm test`를 사용합니다.

## 기능과 저장 범위

- 사람·반려동물 추모 공간 생성 및 필터
- 이름, 생애 날짜, 소개와 선택 사진(최대 2MB)
- 추모 메시지와 브라우저 새로고침 후 기록 유지
- 반응형 화면, 키보드로 접근 가능한 입력과 대화상자

첫 두 공간은 가상의 예시입니다. 데이터는 현재 브라우저의 localStorage에만 저장됩니다. 브라우저 데이터 삭제 시 사라지며 다른 기기나 방문자와 공유되지 않습니다. 중요한 추억의 유일한 보관 용도로 사용하지 마세요. 계정, 서버 저장, 공유 링크 및 백업은 이후 구현이 필요합니다.
